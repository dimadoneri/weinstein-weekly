# Weinstein Weekly — Mega Cap Swing

موقع سوينق أسبوعي مستقل مخصص لـ Large / Mega Caps، مبني على Stage Analysis بأسلوب واينستين.

## التقييم
- Stage Quality: 35%
- Relative Strength vs SPY: 20%
- Weekly Base: 15%
- Volume: 10%
- Distance from 30-week MA: 10%
- Market Regime: 10%

## الكون المستهدف
- افتراضيًا Market Cap >= $50B
- ويمكن رفعه إلى $100B من الواجهة.

## المصادر
- Finviz Elite: الشركة والقيمة السوقية والـScreener والأداء.
- Yahoo Chart API: تاريخ الأسعار.
- Stooq: fallback إذا فشل Yahoo.
